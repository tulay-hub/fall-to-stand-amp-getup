# v1 → v2 改了什么

所有改动都先在离线 MuJoCo（训练同款 MJCF、脚底真实碰撞盒）量过，再决定是否保留。

| # | 改动 | 为什么 | 实测依据 |
|---|---|---|---|
| 1 | 默认关节角 `default_joint_pos_rad` 全部换成官方标准站姿 `walk0821/lens110_13.pkl` 原值：膝 0.30→**0.36**、踝 pitch −0.15→**−0.23804**、髋 roll 左右**符号对调**、踝 roll 0→**±0.002027**、**右肘 +0.8→−0.8** | `q_des = default + scale·a`，旧 default 下"零动作"根本不是平脚站，策略要一直用力撑着；髋 roll 反号和右肘反号还是左右不对称的来源 | 新 default 脚掌倾角 **0.00°**、toe-heel **0.000 mm**、双脚同时贴地；旧 default 倾角 2.00°、脚尖翘 5.85 mm |
| 2 | 踝刚度 kp **5.0 → 30.0**（训练 / 播放 / 实机 config / ROS 安装副本四处同步） | kp=5 时踝是软关节：拿满 effort 36 N·m 需要 **412°** 跟踪误差，物理不可达，踮脚尖也只出 6~7 N·m，策略精调踝没有任何收益 | 改前站立左踝被顶到倾角 31°、压力中心 +96 mm；改后两脚 0.84°/1.33°，承重 112.2 vs 112.8 N |
| 3 | 滑步惩罚换成 `foot_slip_stand` | 原 `mdp.feet_slip` 的 cost 乘了 `active=(\|速度指令\|>0.1)`，而本任务指令恒为 0 → **整轮训练 foot_slip 恒为 0.0000**，等于没这项；"被推一下朝一侧点着脚尖走出去"没人拦 | `slip_velocity_mean` 0.245 → **0.107 m/s**，被推 5 次最远漂 15.6 cm 且回位 |
| 4 | 新增 `over_height_air`（−20，超出站高 5 cm 起算的二次惩罚） | 站高项是 exp 形，跳太高只是"不得分"、没有负代价，所以它不亏；实测被推后骨盆冲到 0.925 m 甚至 2.597 m（腿伸直也只 0.75 m 出头）= 蹬地起跳 | 复测最大 **0.660 m**，腾空消失 |
| 5 | 新增 `feet_sole_flat`（+0.6，高度 ±2.5 cm × 水平速度<0.25 × 两脚都承重 三重门控） | 你要的"正常站立时脚底压平"。第一版做成了"绝对水平 + 0.06 m 宽门控 + 权重 1.5"，结果把起身必需的踝背屈/跖屈一起禁掉，策略退化成锁踝、左右踝拧差 9.7° —— 那版已删。这版只在**站定后**轻微压平 | 门控在恢复途中恒为 0，站立期该项值 0.15/0.6（多数时间不在站定态），脚掌倾角 1° 量级 |
| 6 | 恢复窗口 `max_delay_steps` 500 → **300 步（3 s）** | delay 窗口内 `_terminated_buf` 被压掉，`is_terminated` 的 −200 在"躺在地上"期间完全不触发，躺着只损失每小时 5 分的站高 → 没有任何"必须快起身"的压力，这是恢复速度练不出来的结构性原因 | 起身用时中位 **0.79 s**（从 ≤0.30 m 出生） |
| 7 | 站姿专家素材换成官方 `lens110_13.pkl` → 100 Hz / 8 s / 800 帧静止标准站姿 | 之前那份是我合成的"安静站立"，从走路片段整段继承关节摆动，脚底单帧最大不平整 23.5/27.8 mm、离地 −6.4~+13.8 mm、脚尖朝下帧占比各 42% → 判别器拿它当"站着的长什么样"，策略照着学就是点脚尖 | 新素材脚底不平度 **0.000007 mm**、两脚精确贴地 |
| 8 | 站高奖励 anchor 0.664 → **0.65** | 0.664 其实来自"旧 default 姿态"的贴地高度（实测 0.663755）；姿态修正后几何真值是 0.656756 | anchor 比真值低 6.8 mm，峰值落在"脚掌压实"一侧 |
| 9 | 判摔线 0.35 → **0.44**；`standing_pelvis_height_m` 0.666 → **0.656756**；`real_robot_mapping.joint_order` 由 `null` **补全** | 0.35 会让"塌到刚好不触发终止"成为合法稳态（v1 的 3.5% 站起率就是这么来的）；joint_order 留白等于把最关键的置换丢给部署的人自己猜 | v1 末态高度中位 0.180 m、站起率 3.5% → v2 100% |

## 训练侧对应改动位置

* `src/assets/robots/lens110/lens110_constants.py`：`STAND_KEYFRAME`、`PD_PROFILES["walk"]["ankles"]`
* `src/tasks/amp_loco/config/lens110/rewards.py`：`root_height_progress`、`torso_upright`、新增 `feet_slip_stand` / `over_height_air` / `feet_sole_flat`
* `src/tasks/amp_loco/config/lens110/env_cfgs.py`：anchor、判摔、恢复窗口、出生课程 `z_from=z_to=0.16`（直接从最低点出生，不再退火）、上述三项奖励注册并删掉失效的 `foot_slip`
* `src/assets/motions/lens110/Stand/`：换成官方标准站姿片段
